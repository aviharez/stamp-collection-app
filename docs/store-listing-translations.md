# Store listing translations

Drafts for Play Console → Grow → Store presence → Main store listing → **Manage translations → Add your own translations**.
English stays the default (docs/play-console.md §7). The app itself ships in all of these languages.

Only the name, the short description and the release notes are translated here. A translation needs a full
description too: until it is translated, paste the English one from §7 there (or use Play's paid translation
service). Have a native speaker (a closed tester is ideal) read each one before publishing.
