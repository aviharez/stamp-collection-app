# Store listing translations

Drafts for Play Console → Grow → Store presence → Main store listing → **Manage translations → Add your own translations**.
English stays the default (docs/play-console.md §7). The app itself ships in all of these languages.

Each language has the name, short description, full description (all under 4000 characters) and release notes,
translated from the English in §7. Same tone as the app: casual "kamu" / "tú" / "você" / "tu" / "du".
Machine-quality drafts: have a native speaker (a closed tester is ideal) read each one before publishing.
